# متجر إسلامي: نسخة GitHub Pages

الموقع مكوّن من ملفين:
- `index.html`: شكل الموقع. غالباً مش هتحتاجي تلمسيه.
- `products.json`: **كل بيانات متجرك**: المنتجات والأسعار والعروض ورقم واتساب. دا الملف اللي هتعدّليه.

---

## أولاً: رفع الموقع (مرة واحدة)

1. ادخلي على github.com واعملي حساب.
2. اضغطي **New repository**. اكتبي اسم (مثلاً `islami`) واختاري **Public** وبعدين **Create repository**.
3. اضغطي **uploading an existing file** وارفعي `index.html` و `products.json`، وبعدين **Commit changes**.
4. روحي **Settings ← Pages**. في Branch اختاري `main` والفولدر `/ (root)` وبعدين **Save**.
5. استني دقيقة أو اتنين. هيظهر اللينك فوق: `https://اسم-حسابك.github.io/islami/`

---

## لوحة التحكم (زر يظهر ليكي أنتِ بس)

في الموقع لوحة تحكم كاملة: إضافة وحذف وتعديل المنتجات، والعروض، ورقم واتساب، وصورة الغلاف، من غير ما تفتحي ملف الكود. الزر **مخفي عن الزوار**، ويظهر بس على جهازك بعد ما تربطيه بحسابك مرة واحدة.

### الربط (مرة واحدة)

1. على GitHub: صورة حسابك ← **Settings** ← من القائمة الشمال في الآخر **Developer settings** ← **Personal access tokens** ← **Fine-grained tokens** ← **Generate new token**.
2. اكتبي أي اسم (مثلاً `islami-admin`) واختاري أطول مدة انتهاء متاحة.
3. في **Repository access** اختاري **Only select repositories** وحددي مستودع المتجر بس.
4. في **Permissions ← Repository permissions** خلّي **Contents** على **Read and write**، وسيبي الباقي.
5. اضغطي **Generate token** وانسخي الرمز (بيبدأ بـ `github_pat_`). **بيظهر مرة واحدة بس.**
6. افتحي موقعك من **جهازك** بإضافة `?admin` في آخر اللينك، مثلاً:
   `https://اسم-حسابك.github.io/islami/?admin`
7. اضغطي زر **⚙️ لوحة التحكم** ← تبويب **الربط بـ GitHub**، واكتبي اسم المستودع (`اسم-حسابك/islami`) والرمز، وبعدين **ربط وحفظ على هذا الجهاز**.

(أسماء القوائم في GitHub ممكن تتغير شوية، لكن الفكرة واحدة.)

بعد كدا الزر بيظهر لوحده في جهازك من غير `?admin`، ومبيظهرش لأي زائر.

### الاستخدام اليومي

1. افتحي الموقع واضغطي ⚙️ لوحة التحكم.
2. عدّلي أو أضيفي أو احذفي.
3. اضغطي **حفظ ونشر**.
4. التعديل بيظهر للزوار بعد دقيقة أو اتنين.

### الأمان

- الرمز هو مفتاح الدخول، فاعتبريه كلمة سر. **ماتحطيهوش في أي ملف ولا تبعتيه لأي حد.**
- اربطي من جهازك الشخصي بس. لو دخلتي من جهاز مش بتاعك اضغطي «فصل هذا الجهاز».
- لو ضاع جهازك أو شكيتي في الرمز، امسحيه من GitHub (نفس صفحة Fine-grained tokens ← Delete) واعملي واحد جديد.
- صلاحية الرمز تخص مستودع المتجر بس، فمفيش خطر على باقي حسابك.

## تعديل الملف يدوياً (بديل لو مش عايزة لوحة التحكم)

## ثانياً: تغيير رقم واتساب

1. افتحي `products.json` من الـ repository واضغطي أيقونة القلم ✏️.
2. غيّري السطر:
   ```
   "whatsapp": "201001234567",
   ```
   الرقم بدون + وبدون مسافات، وبكود مصر `20` في الأول. مثال: رقم 01012345678 يتكتب `201012345678`.
3. اضغطي **Commit changes** (الزر الأخضر). التعديل يظهر في الموقع بعد دقيقة تقريباً.

---

## ثالثاً: إضافة منتج

كل منتج بالشكل دا:

```json
{
  "id": 6,
  "name": "عباية كريب سادة",
  "price": 990,
  "old": 0,
  "cat": "abayas",
  "sizes": "S,M,L,XL",
  "img": "images/abaya6.jpg",
  "isNew": true,
  "best": true,
  "off": false
}
```

انسخيه وحطيه **بعد آخر منتج** في القائمة، **وحطي فاصلة `,` بين كل منتج والتاني** (بعد القوس `}`)، وآخر منتج من غير فاصلة.

| الحقل | معناه |
|---|---|
| `id` | رقم لكل منتج ولازم **ميتكررش** (6 ثم 7 ثم 8...) |
| `name` | اسم المنتج |
| `price` | السعر الحالي (أرقام بس) |
| `old` | السعر قبل الخصم، **للعروض**. اتركيه `0` لو مفيش عرض |
| `cat` | القسم: `abayas` عبايات، `khimar` خمر، `isdal` إسدالات، `sets` أطقم كاملة |
| `sizes` | المقاسات، افصلي بينها بفاصلة |
| `img` | مسار الصورة (شوفي تحت) |
| `isNew` | `true` لو عايزة علامة "جديد" وإلا `false` |
| `best` | `true` لو يظهر في "الأكثر مبيعاً" بالرئيسية |
| `off` | `true` لو عايزة تخفيه مؤقتاً (نفد) |

### العروض
اكتبي السعر الجديد في `price` والسعر القديم في `old`. مثال: `"price": 880, "old": 1100`. هيظهر الخصم **-20%** والسعر القديم مشطوب، ويظهر المنتج في قسم "عروض وتخفيضات". لإلغاء العرض خلّي `old` يساوي `0`.

### الحذف
امسحي المنتج كله من `{` لحد `}` مع الفاصلة بتاعته.

## رابعاً: صور المنتجات

1. في الـ repository اضغطي **Add file ← Upload files**.
2. لازم الصورة تكون جوه فولدر اسمه `images`. لو مفيش فولدر بالاسم دا اكتبي `images/` قبل اسم الملف وانتي بتسميه (أو اسحبي فولدر اسمه images فيه الصور).
3. حجم الصورة يفضل أقل من 300 كيلوبايت. استخدمي صور مضغوطة عشان الموقع يفتح بسرعة.
4. في `products.json` اكتبي مسارها: `"img": "images/abaya6.jpg"`. الاسم لازم يكون **إنجليزي من غير مسافات**، والحروف تتطابق بالظبط.
5. لو المنتج بدون صورة بيظهر شكل مؤقت لحد ما تضيفي الصورة.

صورة الغلاف: نفس الفكرة في `"heroImg": "images/hero.jpg"`.

## قواعد مهمة عشان الملف ميتبوظش

- الكلام بين علامات تنصيص `" "` دايماً.
- الأرقام من غير علامات تنصيص، و`true` و`false` بحروف إنجليزي صغيرة ومن غير تنصيص.
- فاصلة `,` بين كل عنصر والتاني، ومن غير فاصلة بعد آخر عنصر.
- لو الموقع ظهرت فيه رسالة «تعذر تحميل المنتجات» يبقى في غلطة في الملف (غالباً فاصلة ناقصة أو زيادة). الصقي محتوى الملف في **jsonlint.com** وهيقولك السطر.
- قبل أي تعديل كبير انسخي محتوى الملف احتياطي.

---

## خامساً: دومين رسمي (اختياري)

1. اشتري دومين من أي موقع (مثلاً islami.com).
2. في **Settings ← Pages** اكتبي الدومين في خانة **Custom domain** واضغطي Save.
3. في موقع الدومين ضيفي إعدادات DNS اللي GitHub بيعرضها في نفس الصفحة، وبعدين فعّلي **Enforce HTTPS**.

## الطلبات

الزبونة بتضيف للسلة وتضغط «إتمام الطلب عبر واتساب»، فتوصلك رسالة جاهزة على رقمك فيها المنتجات والمقاسات والإجمالي. باقي الاتفاق على الدفع والشحن بيتم في الواتساب.
